execution plans

Oracle の実行計画を、上から下まで自分の言葉で説明できるようになるための学習ノート。

DBMS_XPLAN の出力を見たことはあるが、どこから読めばよいか、Rows や Cost が何を意味するかがあいまいな人に向けて書いている。掲載する実行計画は、すべて手元の Docker 環境で実際に取得したものである。

  1. GOAL 01実行計画を正しい順番で読み、処理の流れを言葉で説明できる
  2. GOAL 02見積り（E-Rows）と実績（A-Rows）を比べ、遅さの原因がどの行にあるかを特定できる
  3. GOAL 03アクセスパスと結合方式を見て、なぜオプティマイザがそれを選んだかを推測できる
