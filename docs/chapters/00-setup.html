Docker で Oracle AI Database 26ai Free を起動し、学習用のスキーマを作る。

前提

  • Docker（Docker Desktop / Rancher Desktop など）
  • Docker の VM に 6GB 以上のメモリを割り当てる。4GB では初期化中にスワップが続き、起動が終わらないことがある。Rancher Desktop で Kubernetes を使わない場合は無効にしておく

起動

docker compose up -d
docker compose ps   # STATUS が healthy になるまで待つ（初回は数分かかる）

イメージは gvenzl/oracle-free を使う。起動時にプラガブルデータベース FREEPDB1 と学習用ユーザー study が作られる。

権限の付与とスキーマ作成

# DISPLAY_CURSOR に必要な権限を与える
docker compose exec oracle sqlplus -s system/oracle@FREEPDB1 @/sql/00_grant.sql

# 表とデータを作り、統計を取る
docker compose exec oracle sqlplus -s study/study@FREEPDB1 @/sql/01_schema.sql

最後に表ごとの件数が表示されれば完了である。

接続

docker compose exec oracle sqlplus study/study@FREEPDB1

ホストの SQL Developer や DBeaver からは localhost:1521/FREEPDB1 に接続する。

スキーマ

表 件数 特徴
customers 10,000 region は 5 種類で均等
products 1,000 category は 20 種類
orders 200,000 status が偏っている（SHIPPED 約 98%）
order_items 約 400,000 受注 1 件につき 1〜3 行

orders.status の偏りは、6 章で見積り誤差とヒストグラムを扱うときに使う。

片付け

docker compose down        # 停止（データは残る）
docker compose down -v     # データも削除する
Oracle 実行計画の読み方 — 学習ノート 実行計画はすべて Oracle AI Database 26ai Free（23.26.3）で実測
